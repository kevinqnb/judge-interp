### Implemented

`src/judge_interp/jev.py` mirrors `clef.py` with TypeSafe Jev called over the API: tasks `jev_entity_row`, `jev_relation_conditional` and `jev_record_oneshot` use the same rows, samples, labels and question wording as Clef, with a JSON state, a pinned versioned model id (`experiments/model-configs/jev.yaml`, loaded by `load_jev_model_config`) and `P(true)` only. The API is nondeterministic for an identical request, so the determinism check is a tolerance (`params.determinism_atol`) rather than bitwise equality. `run_experiment.py` registers the tasks without importing torch, and `submit.sh --api` submits CPU-only API jobs that run with the repo's `.env`. Tests use a fake client; configs are the 2026-10-27 `jev` smoke, tiny, context-swap control and full test configs, and the full conditional, one-shot and entity runs are submitted.
